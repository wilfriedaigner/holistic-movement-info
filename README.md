# Holistic Movement – Trainingsarchiv

Öffentliche Informationsseiten für die persönliche Sicherung eigener Trainingsdaten in Google Drive.

- `index.html`: Beschreibung der Anwendung
- `datenschutz.html`: Datenschutzerklärung
- `nutzung.html`: Nutzungshinweise

Die Website enthält keine Trainingsdaten, Zugangsdaten, Formulare oder Tracker. Die Einrichtung der Archiv-Anwendung ist noch nicht abgeschlossen; der tägliche Betrieb wird erst nach erfolgreichen Live-Prüfungen aktiviert.

Veröffentlichung: GitHub Pages aus `main`, Verzeichnis `/`.
